Seaclear Marine Debris Dataset contains 8610 images of marine litter annotated for tasks of object detection and instance segmentation with 40 object categories, encompassing not only litter but also observed animals, plants, and robot parts. Data was captured using ROVs during field experiments related to Seaclear project and thus includes images from multiple locations:

    Bistrina, Croatia
    Jakljan, Croatia
    Lokrum, Croatia
    Slano, Croatia
    Marseille, France

Annotations are available as a COCO format (.json) file, and the images are arranged in folders, each dedicated to a unique site-camera pair. All images are resized to 1920x1080 resolution.
